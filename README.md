# 二、FandaP&nbsp;&nbsp;~&nbsp;&nbsp;反复曲折的曲折反复
## 你就不能发挥一下README.md的作用吗，别浪费时间了，比如说说你的故事。
哦对，我的名字叫FandaP，2012年7月生于广东省深圳市。2018年先后成为《第五人格》和《迷你世界》玩家（这辈子有了）。自8岁起，我就对coding产生了极大的兴趣。但是你不能苛求一个小学生能搞懂这种复杂的东西，所以直到2022年的时候我也只是把Python和C++的部分内容学会，各种类库啥都不知道。

2022年，作为《迷你世界》玩家的我从4399下载了《我的世界：中国版》，也就是广为人知的冈易MC。彼时的《迷你世界》经历了一轮大更新，好多原本的玩法被代替。而作为《迷你世界》抄袭对象的《我的世界》居然让我感受到了《迷你世界》的温暖——这太像老版本的《迷你世界》了,。从此，我沉迷于《我的世界》中。2022年10月，我也用PCL启动器玩上了Java版*Minecraft*，并且心头诞生出了一个做整合包的计划。但是，由于我的提交中一直包含游戏源文件，MC百科的审核不知道拒绝了我多少次。所以，这个计划只能作罢。 

然而在做整合包的过程中我遇上了一位模组作者，他的名字叫墨小云。墨小云非常好心地带我入坑了东方、UT、一半的VOCALOID。从此我成为了一名车万众。随后的两年时光，是从以墨小云为中心的人际网络展开的。同时，我在这一阶段中自认为是一个二次元（尽管看过的番剧数量为0）。

2024年，伴随着**Niconico被攻击**且**二次元环境日渐商业化**，*FandaP*有了一个点子，要做一个网站，代替Bilibili！于是他拉上了他的朋友Nian_Gao，整了些不切实际的想法。这个网站的项目被称为TouVo-，最后当然是以二人的不欢而散为结局。在这一年，FandaP的网络交际圈有了极大的扩展，这得益于……我也不知道得益于什么，可能是会用更多的社交媒体了。

随后，我上初中的二年是无趣的二年（2026年4月6日以后除外）。但随着我重新获得了电脑，我开始重拾编程的爱好，这也就是今天的我。
## 看起来好像是很无趣的故事。
这是相当简略的版本，这个故事实际上是非常悲壮的。你很难想象一个六年级的小学生居然没有自己现实世界的社交。我的同学们不喜欢我，我也讨厌他们，这当然不是他们的错。上文所说的TouVo-其实是现实世界遇上的非常不愉快的友谊。我自己在这样的环境里有轻生念头，想必也几十次了吧。当然我没有勇气踏出那一步，我也永远不会的。  
总之，上网让我很开心，现实世界让我窒息。
